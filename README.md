# 英語音読トレーニングアプリ for LD

学習障害（LD）のある方向けの英語音読トレーニングアプリです。音声認識機能を使って読解力とスピードを鍛えます。

## 🎯 特徴

- **音声認識による音読チェック**: ブラウザの音声認識APIを使用して、実際に声に出して読んだ内容を自動でチェック
- **4択問題形式**: 英検3級レベルの読解問題で理解度を確認
- **WPM（Words Per Minute）測定**: 読書速度を客観的に測定・追跡
- **進捗グラフ表示**: 正答率とWPMの推移を視覚的に確認
- **匿名データ収集**: 学習効果の分析のため、匿名でスコアデータを収集（オプトイン方式）
- **クロスデバイス対応**: ユーザーIDを使用して複数のデバイス間でスコアを共有可能

## 🚀 使い方

1. **アプリにアクセス**: https://itiyabosi.github.io/English-reading-app-for-ld/
2. **スタート画面**: データ収集の同意を確認して「スタート」をクリック
3. **音読**: 「測定開始」ボタンを押して英文を声に出して読む
4. **解答**: 4つの選択肢から正しい答えを選ぶ
5. **結果確認**: 全5問終了後、スコアシートとWPMが表示されます

## 📊 機能詳細

### 音声認識機能

- **リアルタイム認識**: 読んだ内容をリアルタイムで認識・表示
- **精度判定**:
  - 正しく読めた単語: 緑色でハイライト
  - 読み間違えた単語: 赤色でハイライト
  - 読み飛ばした単語: 黄色でハイライト
- **自己修正検出**: 読み直した単語を自動検出して青色で表示
- **精度計算**: 読み飛ばしを考慮した正確な精度測定

### スコア管理

- **ローカルストレージ**: ブラウザに自動保存
- **Firebase連携**: クラウドに匿名でスコアを保存（同意した場合のみ）
- **CSV出力**: スコア履歴をCSVファイルとしてダウンロード可能
- **履歴表示**: 過去のスコアを一覧表示
- **進捗グラフ**:
  - 正答率の推移グラフ
  - WPMの推移グラフ（150+ WPM=優秀、100-150 WPM=良好、100未満=要練習）

### ユーザーID管理

- **自動生成**: 初回起動時にユニークなユーザーIDを自動生成
- **ID共有**: IDを保存して別のデバイスで入力することで同じアカウントを使用可能
- **コピー機能**: ワンクリックでIDをクリップボードにコピー

## 📱 対応ブラウザ

音声認識機能を使用するため、以下のブラウザを推奨します：

- ✅ Google Chrome（最も推奨）
- ✅ Microsoft Edge
- ✅ Safari（iOS/macOS）
- ❌ Firefox（Web Speech APIの対応が限定的）

## 🔒 プライバシー

- 個人を特定できる情報は一切収集しません
- 音声データはサーバーに送信されません（端末内で処理）
- 収集するデータ: スコア、時間、WPM、ブラウザ種類、タイムスタンプのみ
- データ収集はオプトイン方式（チェックボックスで選択可能）

詳細: [プライバシーポリシー](https://itiyabosi.github.io/English-reading-app-for-ld/privacy.html)

## 📦 ローカルでの実行方法

```bash
# リポジトリをクローン
git clone https://github.com/itiyabosi/English-reading-app-for-ld.git

# ディレクトリに移動
cd English-reading-app-for-ld

# ローカルサーバーを起動（Python 3の場合）
python -m http.server 8000

# ブラウザで http://localhost:8000 にアクセス
```
